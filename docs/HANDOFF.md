## 코드로 확인한 한계 (2026-11-13 점검)
- **실제 영상 품질은 미검증.** SAM 2 추적은 합성 영상(노이즈 배경 위 단색 사각형)으로만 측정됐고, 40분 전체 실행도 한 번도 하지 않았다 [확인: README Limitations].
- **앱에 마스크 미리보기가 없다.** `src/app/`에는 SAM 2를 호출하는 코드가 없어서, 점을 찍고 전체 작업을 돌려야 마스크를 볼 수 있다 [확인].
- **마스크를 디스크에 남기지 않는다.** 청크별로 남는 것은 인코딩된 세그먼트와 상태뿐이고, 모자이크 강도·형태가 설정 해시에 들어 있어 강도만 바꿔도 추적부터 다시 돈다 [확인: `src/pipeline.py` `config_hash`].
- **재클릭 비용.** 점이 바뀐 청크부터 영상 끝까지 전부 재계산한다 [확인: `prompt_signatures`].
- **청크 경계.** 경계마다 SAM 2 메모리가 초기화되고 마지막 마스크 하나로 재시드한다. 추적은 앞 방향으로만 간다 [확인: `src/tracking.py`].
- **NudeNet과 SAM 2는 연결돼 있지 않다.** 결과를 합집합으로 모자이크할 뿐, NudeNet 박스가 SAM 2 프롬프트나 재획득에 쓰이지 않는다 [확인].
- **모자이크 설정은 영상 전체에 하나.** 강도는 절대 픽셀값(`block`)이고, 객체별·구간별 설정과 Feather, 브러시 수정은 없다 [확인].
- **NudeNet 실행 환경.** `models/`에 640 모델 파일이 없다(패키지 내장 `320n.onnx`만 있음). 설치된 onnxruntime 1.31.0은 CPU 전용이고, `censor_video.py`는 `providers`를 탐지기에 넘기지 않아 `onnxruntime-gpu`를 설치해도 코드 수정 없이는 CPU로 돈다 [확인].
- 앱은 작업 프로세스에 `--config`를 넘기지 않는다. `config.example.json`의 값은 명령줄 실행에만 적용된다 [확인: `src/app/job_runner.py` `build_args`].

## 다음 작업 (제안, 우선순위 순 — 1번 외에는 사용자 승인 전)
1. **실제 영상 1~2분 구간 테스트.** 어려운 장면(가려짐, 빠른 움직임, 화면 밖 재진입)이 든 구간을 중립적인 파일명으로 `input/`에 두고, 앱에서 클릭 후 fail-closed와 "Keep intermediate chunks"를 켜고 처리한다. 검수 로그와 눈으로 본 문제를 대조해 끊김의 위치와 종류를 분류한다. 이 결과로 2~5번의 순서를 정한다.
2. 청크별 마스크 캐시: 강도 변경 시 렌더만 재실행, 객체별 설정, 미리보기, 브러시 수정의 선행 조건.
3. 모자이크 강도 1~10 정규화(해상도 비율), 객체별 형태/강도, Feather. `points.json`은 버전 2로 올리고 버전 1도 계속 읽게 한다.
4. 클릭 직후 한 프레임 마스크 미리보기, 이어서 브러시 수정(수정 마스크를 `add_new_mask` 프롬프트로 재추적, 전후 비교 후 승인/되돌리기). 수정 전후 마스크와 오류 종류를 기록으로 남긴다.
5. NudeNet → SAM 2 제한적 연결: 놓친 대상 재획득, 새 대상 후보 제안(승인제). 합집합은 유지한다.
6. NudeNet 640 모델 다운로드, `onnxruntime-gpu`와 `providers` 연결 (패키지 설치는 사용자 승인 필요).
7. 데스크톱 앱 5~6단계, EXE 패키징.
